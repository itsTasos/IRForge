# Dependencies and redistribution

The YARA-X lock audit verifies all 475 registry-crate checksums and retains 822 license/notice texts under `assets/licenses/yara-transitive`. It conservatively includes unbuilt platforms/features. Release companions contain the upstream source and all locked `.crate` source archives; `locked-crates.json` records SPDX declarations and original URLs, including crates without a separate license file. These retained sources also cover MPL portions. Independent redistribution review is still required before a public commercial release.

dependencies.lock.json pins archive hashes and versions. IRForge source is MIT. SQLite 3.53.4 is public domain; JSON 3.11.3 and yaml-cpp 0.8.0 are MIT; tinyxml2 11.0.0 uses zlib; YARA-X 1.21.0 is BSD-3-Clause. Catch2 3.7.1 is BSL-1.0 and is only in test binaries. Original benign rule packs are MIT; Sigma samples retain their own notices. The generated ATT&CK v18.0 subset includes source and terms; mappings describe behavioral alignment.

Qt 6.8.3 QtBase uses replaceable dynamic DLLs under LGPL-3.0, with bundled third-party notices. Package licenses/qt and licenses/qt-thirdparty retain texts. qtbase-corresponding-source-6.8.3.tar.xz accompanies artifacts, unchanged, with upstream build instructions. Users may replace compatible Qt libraries and debug modifications; IRForge imposes no restriction on reverse engineering for that purpose. Build application source with scripts/build.ps1. No Qt library is statically linked and no proprietary Qt module is used.

GCC runtime uses GPL-3.0 plus Runtime Library Exception 3.1; MinGW-w64 contains ZPL/BSD/public-domain portions and separately marked components. Texts accompany the bundle. Qt's MinGW13 runtime accompanies the GCC15-built application; dependency/portable smoke evidence is in the status report. The official YARA-X DLL archive name includes msvc; its imports require Windows system DLLs, not Visual Studio or MSVC runtime. Upstream YARA-X source/Cargo.lock accompany release artifacts for transitive dependency inspection.

WiX 6.0.2 is a development-only MSI tool. Its binary distribution agreement requires a maintenance fee for revenue-generating use; review official terms for your deployment. WiX is not installed with IRForge. .NET, 7-Zip, Python, cryptography, jsonschema, stix2-validator and clang-format are build/test tools, not endpoint prerequisites.

VirusTotal is optional. Its [Public API restrictions](https://docs.virustotal.com/reference/public-vs-premium-api) include 4 requests/minute, 500/day and restrictions on commercial products and business workflows without contributing new files. IRForge does not upload files; deployments must obtain suitable permission/entitlement. The conservative budget is enforced even with a paid credential.
