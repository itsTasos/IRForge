# Operational boundaries and validation limits

- IRForge is a visible user-mode lab platform. Administrators/OS compromise can stop or tamper with it. No kernel prevention, stealth, remote execution, uploads, automatic quarantine, process killing or system remediation exists.
- ETW requires tracing permission. Sysmon/Event Log needs installed providers, enabled event categories and channel access. Missing data is recorded as disabled/degraded/gap, never inferred benign. No audit policy or Sysmon configuration is changed. Current live coverage and error codes are in each run's health file.
- TCP4/6 uses polling; short sockets can be missed and observed rows do not prove initiation, packets or C2. Sysmon adds source-qualified timing when present. UDP remote peers and WFP/packet capture are outside this implementation.
- Native file and Registry actors remain unknown. SCM/tasks/Startup/extended Registry are snapshots/differences; a change reverted between scans can be missed. Partial reads preserve prior entries. Unloaded user hives are outside scope. No timestamp-only or PID-only causal attribution is used.
- Final-handle containment excludes outside-root junction targets. Hashing/YARA record their observed bytes/identity and detect changes; concurrent modification can still occur between scans. Default automatic enrichment only handles executable/script/archive extensions under explicit roots. No arbitrary user document scraping occurs. Offline signature checks cover embedded PE signatures and cached revocation; catalog signatures and an exhaustive revoked/certificate-chain test matrix are not validated.
- Watch notifications can overflow. Gaps include bounded current-state reconciliation (1024 entries/two seconds) and cannot reconstruct lost change history or writers. Queues, history, graph, scan concurrency/time/size, store quota, remote framing/spool and export rows are bounded. Limits are visible; high-volume throughput is not promised.
- YARA workers have real watchdog/cancellation/reload tests, but there is no proof against every hostile rule/OS failure. Internal markers are benign patterns, not malware signatures. Sigma is the documented tested subset, with unsupported constructs rejected. ATT&CK is a pinned reviewed compact subset; mappings are context, not proof of an attack.
- Baselines need explicit learning/freeze and minimum samples; updates/software changes can be rare but normal. Reputation/local IOC/YARA each contribute capped context. Scores are heuristic rule sums, not calibrated probabilities. Analyst states are independent of activity expiration and require human decisions.
- Command lines, persistence XML/values, paths and endpoints can contain secrets. Local private ACLs do not restrict Administrators/backup privileges. Remote metadata is redacted and authenticated but still reveals endpoint context; no hardware attestation is provided. Raw EVTX export is explicit. Review PRIVACY.md before collecting/exporting.
- Only one logical owner opens a database. Stopping the backend is necessary for offline CLI writes/exports; live GUI reads use IPC. Crash recovery/quota/parser/TLS fixtures passed locally, but power-loss/storage-controller faults and clean-VM reboot acceptance remain separate gates.
- Remote TLS tests are actual loopback transport with ephemeral PKI and synthetic labeled observations. They do not establish two-VM/NAT/firewall acceptance. Unknown CAs, hostname/pin mismatch, no client certificate, revoked identity, host impersonation and unauthorized queries are rejected. No certificate-store changes were made. Collector queries trust enrolled source observations.
- Online VirusTotal validation is NOT RUN: no authorized credential/provider entitlement. Signing is NOT RUN: no owner signing material. Privileged service install/start/reboot/uninstall, controlled persistence mutation, MSI clean-machine upgrade/rollback and two-VM transport are NOT RUN. No IRForge service was installed on the development host. Hosted build/package CI is prepared; no successful hosted run is claimed. The development test suite and recordings remain local and are excluded from this release repository.
- Compiler warnings are errors in owned production C++. Parser smoke fuzzing is bounded/seeded, not exhaustive; MinGW sanitizer execution is NOT RUN. Dependency license texts/source are retained, including a conservative Cargo.lock audit; independent legal/security review remains a public-release gate. Package binaries are unsigned.
